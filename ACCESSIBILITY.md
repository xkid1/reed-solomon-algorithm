# Accessibility

This repository provides a TypeScript library rather than a user interface. Accessibility still matters in its documentation, contribution process, issue forms, and any examples or interfaces added in the future.

We aim to:

- Use descriptive headings, link text, and plain language in documentation.
- Keep examples readable and provide text alternatives when an explanation depends on a diagram or image.
- Make issue forms understandable without relying on color, visual layout, or a specific input device.
- For any future interactive demo or UI, support keyboard operation, visible focus, screen readers, sufficient contrast, and content that remains usable when zoomed.

If you encounter an accessibility barrier in this repository, [open an issue](https://github.com/xkid1/reed-solomon-algorithm/issues). Include the affected page or workflow, what you were trying to do, and the assistive technology or browser details if you are comfortable sharing them. Avoid including private or sensitive information.
