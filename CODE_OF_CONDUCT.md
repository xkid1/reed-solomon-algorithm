# Code of Conduct

We want this project to be a respectful, useful place to collaborate. Participants in issues, pull requests, reviews, and other project spaces are expected to:

- Be considerate and respectful, including when disagreeing.
- Critique ideas and code constructively; do not attack or demean people.
- Make space for different backgrounds, experience levels, and communication styles.
- Accept feedback and corrections in good faith.
- Avoid harassment, discrimination, personal attacks, and unwanted disclosure of private information.

Project maintainers may edit, remove, or decline contributions that do not meet these expectations, and may restrict participation in serious or repeated cases.

To report a conduct concern, contact the repository maintainers privately through GitHub. Do not include sensitive personal information in a public issue. For a security vulnerability, follow the private reporting instructions in [SECURITY.md](SECURITY.md).
